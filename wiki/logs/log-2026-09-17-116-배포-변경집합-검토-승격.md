GitHub Actions `Deploy CS Wiki`의 114·115 실행이 `Validate change set`에서 실패했다. 기존 `active` 페이지를 바꿨지만 `review.mode`가 `legacy-baseline`으로 남아 `review.attestation` 오류가 났다.

## 변경

- 마지막 성공 배포(`cd5d0c5`) 이후 바뀐 공개 위키 페이지 154개를 `review.mode: attested`로 올렸다.
- `scripts/update_wiki_updated.mjs`가 한글 경로를 C 인용 문자열로 받아 파일을 놓치던 문제를 NUL 구분(`-z`)으로 고쳤다.

## 검증

- `BASE_SHA`를 현재 `origin/main`으로 두고 `npm run validate:changes`
- `npm run lint:wiki`
- `npm run maintenance:check`
